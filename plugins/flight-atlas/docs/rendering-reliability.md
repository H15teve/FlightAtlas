# 报告问题复盘与处理原则

| 问题 | 原因 | 插件处理 |
| --- | --- | --- |
| 花体签名碰到护照标题 | 签名复用身份姓名，大小写变化会改变字宽；按字号放置没有约束实际字形边界 | `signature_name` 与身份姓名分开；保留用户输入大小写，允许全大写；按字形边界在标题右侧独立区域等比例缩放 |
| 航司较多时中国地图变形 | 航司栏与地图容器同步增高，地理范围被分别按宽、高拉伸；嵌入 SVG 又允许非等比例缩放 | 容器可增高，地理图形保持中心和纵横比；主图与南海附图均保留比例；SVG 使用 `xMidYMid meet` |
| LOGO 偏上或显得过小 | 原素材画布含不对称透明边距；SVG 的 viewBox 也可能包含大量空白 | PNG 与 SVG 均测量渲染后可见图案边界，在统一宽、高上限内居中缩放；保留原素材和完整图案，不使用航司专属偏移 |
| 状态核验完成但卡片机龄仍为空 | 注册号、MSN 和当前状态不等于首次交付日期；旧覆盖率只反映状态 | 预检分别返回状态覆盖率和机龄覆盖率，并列出所选卡片缺交付依据的注册号；用户可授权查询或接受未知 |
| 月精度或来源分歧被迫显示未知 | 原机龄路径只支持精确日期，缺少有界估算的输入与显示 | 精确日、日期区间分别保留；同一位小数的有界结果显示 `≈`，否则显示年龄区间；不将制造、登记、首飞或调机日自动视为交付日 |

## 核验要求

- 签名测试覆盖混合大小写、全大写和长全大写；不能通过禁止大写解决排版问题。
- 在不同高度的航司栏中比较地理图形纵横比，保持主图与附图的原始地理要素。
- 使用不同大小、不同空白边距的合成 PNG/SVG，核对实际图案中心和显示尺寸一致；同时覆盖航司条形行与小 LOGO 网格的尺寸上限。
- 区间机龄要求匹配注册号/MSN、来源和用户采纳；拒绝反向、未来、格式错误及相互冲突的区间。
- 状态核验、交付日期完整度和所选卡片机龄完整度分别报告。预检先应用已有用户确认的补充数据，再指出尚缺的字段。
- 保留原表、原素材和来源精度。未知不显示为零；不得为填满卡片编造日期。

改动后的正式报告仍需核对计数、地图标签及素材，并打开两张 PNG 检查实际排版。自动检查不能代替图片核对。
